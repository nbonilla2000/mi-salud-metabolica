# Mi Salud Metabólica - Versión PWA sin instalar Flutter

Esta versión evita instalar Flutter, Android Studio o SDKs.

## Cómo usarla

1. Sube esta carpeta a un hosting sencillo con HTTPS, por ejemplo GitHub Pages, Netlify, Vercel o cualquier hosting web.
2. Abre el enlace desde Android o iPhone.
3. En Android: menú del navegador Chrome > **Agregar a pantalla principal**.
4. En iPhone: Safari > botón compartir > **Agregar a pantalla de inicio**.

## Qué incluye

- Creación inicial de usuario.
- Registro diario Omron HB514.
- Dashboard.
- Health Score.
- Riesgo metabólico.
- Gráfico histórico.
- Historial.
- Exportar JSON.
- Exportar CSV.
- Importar JSON.

## Privacidad

Los datos se guardan localmente en cada teléfono. Tú y tu pareja tendrán historiales separados.

## Limitación

No es APK ni IPA. Es una Web App instalable. Es la forma más simple de usarla en Android y iPhone sin pelear con SDKs ni antivirus.
